# Security policy

Do not disclose KoPOS connector vulnerabilities, credentials, customer records, receipt evidence, bank references, database dumps, or signing material in a public issue.

Report vulnerabilities through the repository's private vulnerability-reporting feature. Include the exact `erp-connector-vX.Y.Z` release or commit, affected endpoint, required privileges, impact, and redacted reproduction steps. Use sandbox payment accounts and synthetic data only.

Only the currently deployed connector release lines receive fixes. A connector release is valid only when its namespaced tag, immutable commit, automated checks, live ERP smoke evidence, and release manifest agree.
